# zzzbees.com

One static page. No framework, no build step. Edit the files in `site/`, commit, push to `main`, and Netlify publishes it.

## Layout

```
site/            what gets published
  index.html     the page, with its CSS in a <style> block at the top
  images/        web-sized photos and logo, generated by the script below
  icons/         favicons
photos/          full-size originals (source for the script, not published)
scripts/         images.mjs, the shrink script
design/          the Claude Design brief and export the page was built from
netlify.toml     publish folder and redirects from the old /about and /store URLs
```

## Editing text or styles

Open `site/index.html`. The words are in the body, the styles are in the `<style>` block in the head. The CSS is inlined on purpose: it saves a network round trip on every visit, which is the difference between a Lighthouse score of 99 and 100 on a slow phone.

## Tooling

The scripts need Node 24 or newer. With nvm, `nvm use` picks it up from `.nvmrc`.

## Adding or replacing a photo

1. Drop the original JPEG into `photos/`.
2. Run the shrink script once:

   ```sh
   npm install      # first time only
   npm run images
   ```

   It writes AVIF, WebP, and JPEG versions at 480, 800, and 1200 pixels wide into `site/images/`.
3. Reference the new files from `site/index.html` the same way the existing `<picture>` blocks do.
4. Commit the originals and the generated files together.

## Previewing locally

```sh
npm run serve
```

Then open http://localhost:8000. Plain `open site/index.html` also works.

## Checking the budget

```sh
npm test
```

Serves `site/` locally, runs Lighthouse in mobile mode, and fails if the performance score drops below 99, the page transfers more than 300 KB, any JavaScript loads, the layout shifts, or `index.html` references a file that doesn't exist. Run it before pushing. It needs Chrome; set `CHROME_PATH` if it can't find one.

## Deploying

Netlify deploys `site/` on every push to `main`. Settings live in `netlify.toml`, so the Netlify UI should have no build command, no plugins, and the publish directory should show as `site`.
